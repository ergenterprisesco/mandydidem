# mandydidem — Nail Atelier

Mobile-first website for **mandydidem**, a nail artist in Riverside, California.
Nail art · acrylic · gel-x. Bookings go to Instagram DMs.

## Structure

- `index.html` — the entire site (single page, no build step)
- `images/` — portrait and lookbook photos

Static site — deploy as-is, no framework or build command.

## Updating photos

Replace any file in `images/` keeping the same name:

- `mandy.jpg` — portrait in "The Artist"
- `nail1.jpg` … `nail6.jpg` — lookbook grid, in order

Tiles crop to a uniform size automatically, so photo dimensions don't need to match.
